# Journeyletter

Field notes on operating AI agents for real work — from a publication that is itself run
as an agent operation. Live at **[pezilabs.com/notes/](https://pezilabs.com/notes/)**,
published by [Pezi Labs](https://pezilabs.com).

Every piece ends with a colophon naming the stack, the agents that did the work, and
exactly what the human did. The colophons are structured frontmatter (`src/content.config.ts`),
so the archive is queryable: over time they are the experiment — watch the human's role
shrink from author to editor to mentor, with receipts. This repo is public for the same
reason: the commit history *is* the receipts.

Built with Astro (static, zero client JS), deployed on Vercel on push to `main`.
Editorial rules — exhaust not authorship, cadence by accumulation, the wall, full
transparency — are on the [about page](https://pezilabs.com/about/).
